## 6. Accesibilidad

### 6.1 Directrices WCAG 2.1 AA

**Contraste de Colores:**
- Texto normal: ratio mínimo 4.5:1
- Texto grande: ratio mínimo 3:1
- Verificar con herramientas (WebAIM)

**Navegación por Teclado:**
- Todos los elementos interactivos accesibles con Tab
- Orden lógico de tabulación
- Focus visible (outline azul)
- Skip navigation link

**Semántica HTML:**
```html
<header>
  <nav aria-label="Navegación principal">
    <a href="/" aria-current="page">Inicio</a>
  </nav>
</header>

<main>
  <h1>Productos</h1>
  <section aria-label="Filtros de productos">
    <!-- Filtros -->
  </section>
  
  <section aria-label="Lista de productos">
    <article>
      <img src="..." alt="Manzanas rojas frescas">
      <h2>Manzanas Rojas</h2>
      <button aria-label="Agregar Manzanas Rojas al carrito">
        Agregar
      </button>
    </article>
  </section>
</main>

<footer>
  <!-- Footer content -->
</footer>
```

**Atributos ARIA:**
```html
<!-- Botones con iconos -->
<button aria-label="Buscar productos">
  <i class="icon-search" aria-hidden="true"></i>
</button>

<!-- Estado de carga -->
<button aria-busy="true" aria-live="polite">
  Procesando...
</button>

<!-- Modales -->
<div role="dialog" aria-labelledby="dialog-title" aria-modal="true">
  <h2 id="dialog-title">Confirmar eliminación</h2>
  <!-- Contenido -->
</div>

<!-- Alertas -->
<div role="alert" aria-live="assertive">
  Producto agregado al carrito
</div>
```

**Textos Alternativos:**
- Imágenes informativas: alt descriptivo
- Imágenes decorativas: alt=""
- Iconos funcionales: aria-label

**Formularios Accesibles:**
```html
<label for="email">Email *</label>
<input 
  id="email" 
  type="email" 
  required 
  aria-required="true"
  aria-describedby="email-error"
>
<span id="email-error" role="alert">
  El email debe ser válido
</span>
```
