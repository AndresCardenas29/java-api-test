💾 BASE DE DATOS
═════════════════

Tablas Principales:
├─ users (usuarios del sistema)
├─ products (catálogo de productos)
├─ categories (categorías de productos)
├─ orders (pedidos realizados)
├─ order_items (items de cada pedido)
├─ payments (transacciones de pago)
├─ addresses (direcciones de entrega)
├─ cart_items (carrito de compras)
├─ wishlist (lista de deseos)
├─ product_images (imágenes de productos)
├─ refresh_tokens (tokens JWT)
└─ order_status_history (historial de estados)

Relaciones:
├─ 1:N → User → Orders
├─ 1:N → User → Addresses
├─ 1:N → Order → OrderItems
├─ 1:1 → Order → Payment
├─ N:1 → Product → Category
├─ 1:N → Product → ProductImages
└─ N:M → User ← Cart → Product

⚠️ RIESGOS IDENTIFICADOS
══════════════════════════

1. Integración de Pasarela de Pagos
   └─ Mitigación: SDK oficial, testing exhaustivo

2. Rendimiento con Carga Alta
   └─ Mitigación: Caching (Redis), auto-scaling

3. Seguridad de Datos
   └─ Mitigación: OWASP, auditorías, PCI-DSS

4. Problemas de Inventario
   └─ Mitigación: Transacciones atómicas, alertas

5. Retrasos en Cronograma
   └─ Mitigación: Buffer 20%, sprints ágiles

6. Cambios de Requerimientos
   └─ Mitigación: Proceso formal de cambios

7. Disponibilidad de Recursos
   └─ Mitigación: Documentación, pair programming

8. Adopción de Usuarios
   └─ Mitigación: UX intuitivo, beta testing

9. Competencia
   └─ Mitigación: Diferenciación, calidad, precios
